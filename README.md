# simple_upload

Simpel webbased software for upload a less of data.

## Start

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Danach im Browser öffnen: <http://127.0.0.1:5000>

## Funktionen

- Mehrere Dateien gleichzeitig hochladen
- Alle hochgeladenen Dateien auf der Seite aufgelistet
- Alle hochgeladenen Dateien als ZIP herunterladen
